First operating sequence

Establish the baseline before changing the system.

  1. Confirm the Workspace. Check the organization name, Admin access, and plan.
  2. Invite the right team. Add Analysts and participants only for the work they need to do.
  3. Run a baseline Diagnostic. Start with the lens closest to the operating constraint you need to understand.
  4. Review Analysis and build the Action Plan. Keep every recommendation traceable to measured evidence.
  5. Assign ownership and remeasure. Decide who acts, which indicators move first, and when the next read occurs.
