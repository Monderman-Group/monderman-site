Live QC Matrix

144 controlled fixtures across all four instruments, three run lengths, three vantages, and four semantic answer patterns. Organization context, pathway, sector, and sizing stay fixed so a changed score can be attributed to the diagnostic inputs. Each fixture drives the real API (start, answer, finalize), then injects the result into the real instrument page to scrape the actual deliverable prose, then runs QC on both the numbers and the language. Stop is safe at any point and the JSON stays downloadable. Note: finalize is rate limited per IP, 12 per 10 minutes by default, so the full matrix takes about two hours unless you raise AI_LIMIT_FINALIZE in Render for the duration of the run. A 429 now pauses and retries rather than failing the fixture.
